01 · Agentic Memory Core Concepts

短期記憶 vs. 長期記憶

代理人每次請求都與 LLM 各自獨立;沒有記憶,對話就會失去脈絡與個人化體驗。

短期記憶(Short-term)

  • ✓維持原始資料:對話上下文、Session 屬性
  • ✓代理人狀態 / Checkpoint
  • ✓回答「我們剛剛討論了什麼」

長期記憶(Long-term)

  • ✓維持處理後資訊:使用者偏好、Session 摘要
  • ✓學習事實與概念,客製代理人行為
  • ✓回答「這位使用者是誰、我們學到了什麼」
01 · Agentic Memory Core Concepts

代理人記憶的三大用途

情境智能

維持單一 Session 內的對話流暢度,理解正在進行的任務。

使用者偏好

記住明確偏好與行為模式,跨多個 Session 個人化互動。

知識保留

持續學習並累積跨互動的事實、實體與關係。

02 · AgentCore Memory

長期記憶萃取策略

Summary

凝結對話內容與結果為摘要

User Pref.

學習使用者行為與互動風格的固定模式

Semantic

維護事實與領域知識、技術概念及其關係

Episodic

擷取有意義的互動片段,理解情境演變

Custom

自訂 Prompt 與模型,量身打造萃取邏輯

從短期到長期記憶的生命週期:

Raw Events
CreateEvent 寫入短期記憶
Memory Extraction
每 K 則訊息 / 閒置 X 秒後觸發
Consolidation
比對既有記憶,ADD / UPDATE / SKIP
Long-term Memory
Embedding & 向量索引,供語意檢索

Namespace 以階層路徑組織記憶,例如:

/summaries/{actorId}/{sessionId}   ·   /users/{actorId}/preferences
03 · Securing AgentCore Memory

挑戰與安全防護

儲存可擴展性記憶量成長對檢索速度的挑戰
記憶更新維持記憶內容的即時性與正確性
整合複雜度跨系統串接的工程負擔
隱私與安全防止記憶投毒與跨用戶資料外洩
檢索準確度語意檢索需持續調校相關性
可觀測性需追蹤記憶操作與異常模式

透過 IAM 情境鍵(actorId、sessionId、namespace、strategyId)實作細緻存取控制,確保多使用者、多 Session 記憶的隔離。
