03 · AgentCore Gateway

統一連接層:AgentCore Gateway

將既有 API、Lambda 函式與 MCP 伺服器轉換為代理人可存取的統一工具目錄,解決企業工具氾濫的問題。

統一工具存取

單一整合點管理所有外部服務,支援自然語言語意搜尋。

驗證處理

透過 OAuth(如 Cognito)集中管理憑證、Token 更新與輪替。

協定支援

實作 MCP,並處理 REST、GraphQL 等協定轉換。

多重目標類型

依環境 / 區域 / 服務實例路由請求,分流開發與正式流量。

三種常見 Target 類型:

REST APIs

具備 OpenAPI 規格的既有 API,零程式碼轉為 MCP 工具。

Lambda Functions

自訂商業邏輯,開發專用工具並透過 Gateway 對外曝露。

MCP Servers

群組多個既有 MCP 伺服器於單一可管理介面之下。

04 · AgentCore Policy

以 Cedar 政策守護代理人邊界

攔截每一次 MCP 工具呼叫,在請求離開代理人執行情境前於 Gateway 邊界完成授權判斷。

// "只允許財務部門申請低於 $1000 的報帳" permit( principal, action == MCP::Action::"process_reimbursement", resource ) when { principal.department == "finance" && resource.amount < 1000 };
Effect(permit/forbid) Scope(principal/action/resource) Condition(when/unless)
預設拒絕(default-deny) · forbid 永遠覆蓋 permit · LOG_ONLY 先行驗證,再切換 ENFORCE
