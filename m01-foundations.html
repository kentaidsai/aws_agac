01 · Agent Building Blocks

傳統 AI 與 Agentic AI 的差異

Agentic AI 從被動輸出轉為主動循環:能自主決策、朝目標邁進、理解情境變化,並透過經驗調整策略。

生成式 AI 應用(線性流程)

User→ Invoke model→ Application→ Response

單次呼叫模型、產生回應,不具備持續規劃與工具調用的循環。

Agentic AI 應用(循環流程)

User→ Invoke agent→ Application ⇆ LLM ⇆ Tools
↻ Agentic Loop — 循環至產生推理與工具選擇
  • ✓自主決策(Making independent decisions)
  • ✓朝目標邁進(Working toward objectives)
  • ✓情境感知(Understanding changing conditions)
  • ✓經驗學習(Adapting through experience)
01 · Agent Building Blocks

Agent 的五大核心元件

五個元件彼此依賴、互相增強,而 Security 與 Observability 貫穿所有元件,而非獨立一塊。

Security

保護記憶中的敏感資料、以驗證授權管控工具存取、防止提示注入攻擊,並確保代理人間的安全通訊。

Observability

記錄決策過程、追蹤工具使用、監控跨元件效能,並具備稽核多代理人互動的能力。

Framework / Agent Code

協調代理人行為,管理元件互動與工作流程執行的協調層。

LLM

負責推理、決策並生成回應的核心引擎。

Memory

短期維持對話情境,長期保存知識與使用者偏好。

Tools

串接外部系統、API 與服務,執行真實世界的動作。

Other Agents

支援多代理人協作、資訊共享與複雜工作流程協調。

02 · Amazon Bedrock AgentCore

AgentCore 服務全覽

九項服務可獨立使用,亦可組合搭配,並相容任何模型(Any model)、任何框架(Any framework)、任何代理人(Any agent)。

執行與整合(建置、部署、控管)
記憶與洞察(情境、監控、評估)

Runtime

專為代理人設計的無伺服器執行環境,支援容器與直接程式碼部署。

Identity

雙向驗證代理人與使用者身份,管理存取權限與稽核軌跡。

Gateway

自動化工具發現與註冊,將 API、Lambda 轉為代理人可用工具,支援 MCP。

Browser

全託管無伺服器瀏覽器,於隔離環境中執行網頁互動與內容擷取。

Code Interpreter

於隔離沙箱中安全執行程式碼,支援資料分析與檔案處理。

Policy

以 Cedar 政策語言即時攔截並授權每一次工具呼叫,預設拒絕。

Memory

短期維持對話上下文,長期保存使用者偏好與知識。

Observability

端對端追蹤、除錯與效能監控,相容 OpenTelemetry。

Evaluations

以 LLM-as-a-Judge 進行線上與隨選品質評估。
